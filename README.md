Controls (Keyboard & Mouse):
- WASD to move
  - Same function while swinging
- Spacebar to jump
  - Spacebar to retract tongue when swinging
- Left Shift to leap 
- Hold Left Click/LMB/M1 to latch for swinging 
- click right Click/RMB/M2 to grapple (only flies can be grappled to)
- R to reset 

How to Play:
- Use the movement mechanics to get around the environment, jump on mushrooms to bounce, use anything you can latch
  onto to swing around and gain height by holding Spacebar while using WASD to move maneuver. See if you can find 
  the 6 hidden hats around the environment

Expected Content Experience
- A smooth movement based exploration game where you find and collect hats

Known Issues:
- Some (hyper-specific) places prevent the player from moving forward and/or jumping, those being the leaves on the
  plants
- Swinging and grappling can be used together, causes no issues but isn't intended and will be removed
